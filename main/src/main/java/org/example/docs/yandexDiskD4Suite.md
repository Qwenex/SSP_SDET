# Тест-сьют: Yandex Disk D4

**Базовый URL:** `https://cloud-api.yandex.net`

---

## Чек-лист

1. Создание папки
2. Удаление существующей папки
3. Восстановление удаленной папки
---

## Тест-кейс № D4-CR1
### Создание папки (Позитивное)

**Предусловия:**
- Существует валидный токен авторизации OAuth для тестирования
- Пользователь авторизован (токен передан через header)

**Шаги:**
1. Установить в параметре запроса `path` любое значение
2. Создать папку, отправив `PUT`-запрос на эндпоинт `/v1/disk/resources`

**Ожидаемый результат:**
- HTTP-код: `201 Created`
---

## Тест-кейс № D4-CR2
### Создание папки (Негативное)

**Предусловия:**
- Существует валидный токен авторизации OAuth для тестирования
- Пользователь авторизован (токен передан через header)

**Шаги:**
1. Создать папку, отправив `PUT`-запрос на эндпоинт `/v1/disk/resources` без указания параметра `path`

**Ожидаемый результат:**
- HTTP-код: `400 Bad Request`
- Тело ответа в формате JSON с параметром `"message"`: `"Ошибка проверки поля \"path\": Это поле является обязательным."`
---

## Тест-кейс № D4-DEL1
### Удаление папки

**Предусловия:**
- Существует валидный токен авторизации OAuth для тестирования
- Пользователь авторизован (токен передан через header)

**Шаги:**
1. Установить в параметре запроса `path` любое значение
2. Создать папку, отправив `PUT`-запрос на эндпоинт `/v1/disk/resources`
3. Установить в параметре запроса `path` значение из шага 1
4. Удалить папку, отправив `DELETE`-запрос на эндпоинт `/v1/disk/resources`

**Ожидаемый результат:**
- HTTP-код: `204 No Content`
---

## Тест-кейс № D4-REC1
### Восстановление удаленной папки

**Предусловия:**
- Существует валидный токен авторизации OAuth для тестирования
- Пользователь авторизован (токен передан через header)

**Шаги:**
1. Установить в параметре запроса `path` любое значение
2. Создать папку, отправив `PUT`-запрос на эндпоинт `/v1/disk/resources`
3. Установить в параметре запроса `path` значение из шага 1
4. Удалить папку, отправив `DELETE`-запрос на эндпоинт `/v1/disk/resources`
5. Получить список удаленных файлов, отправив `GET`-запрос на эндпоинт `/v1/disk/trash/resources`
6. Найти и скопировать новый путь удаленной папки
   > **Пример:**  
   > Если название папки было `TestDir123`, то новый путь будет таким: `TestDir123_<40 символов>`
7. Установить в параметре запроса `path` значение из шага 6
8. Восстановить папку, отправив `PUT`-запрос на эндпоинт `/v1/disk/trash/resources/restore`

**Ожидаемый результат:**
- HTTP-код: `202 Accepted`
