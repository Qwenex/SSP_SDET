# Тест-кейсы API Yandex Disk

## Предварительные требования
Для реализации автотестов API Диска необходимо:
1. Авторизоваться в Яндекс ID
2. Перейти в Полигон по ссылке: [https://yandex.ru/dev/disk/poligon/](https://yandex.ru/dev/disk/poligon/)
3. Получить токен, нажав на кнопку "Получить OAuth-токен"

### Основные параметры
- **Базовый URL для запросов:** `https://cloud-api.yandex.net`
- **Авторизация:** Полученный в п. 3 токен (`auth_token`) должен быть указан в заголовках (Headers)
при каждом запросе, если не указано иное: `{Authorization: auth_token}`
---

## Тест-кейс №1. Авторизация с валидным токеном
**Шаги:**
1. Отправить `GET` запрос по адресу `v1/disk/`

**Ожидаемый результат:**
- **Код ответа:** `200 OK`
- **Тело ответа:** содержит поле `"user"`, в котором поля `"login"` и `"display_name"` соответствуют данным пользователя
---

## Тест-кейс №2. Авторизация без токена
**Шаги:**
1. Отправить `GET` запрос по адресу `v1/disk/` без передачи токена

**Ожидаемый результат:**
- **Код ответа:** `401 UNAUTHORIZED`
- **Тело ответа:** содержит поля `"error"`, `"description"`, `"message"`
---

## Тест-кейс №3. Загрузка и копирование файла
**Предусловие:**
- Создать папки `input_data` и `output_data`
**Шаги:**
1. Сгенерировать текстовый файл `data.txt` с данными:
username=SDET
password=secret_key
2. Загрузить файл в папку `input_data` `PUT` запросом по адресу `/v1/disk/resources/upload`
3. Скопировать `data.txt` из `input_data` в `output_data` `POST` запросом по адресу `/v1/disk/resources/copy`
4. Повторить шаг 3

**Ожидаемый результат:**
- **Шаг 2**
  - Код ответа: `200 OK`
- **Шаг 3**
  - Код ответа: `201 CREATED`
  - Тело ответа содержит: `"name"`, `"mime_type"`, `"media_type"`
- **Шаг 4**
  - Код ответа: `409 CONFLICT`
  - Тело ответа содержит: `"error"`, `"description": "message"`

**Постусловие:**
- Удалить папки `input_data`, `output_data`
---

3. 
**Шаги:**
1. Получить ссылку на скачивание файла `data.txt` `GET` запросом по адресу `/v1/disk/resources/download`
